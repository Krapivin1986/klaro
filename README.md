# Klaro

Лендинг SaaS-продукта для команд удержания: утренняя очередь из десяти клиентов, которым ещё можно помочь, с причиной и первым абзацем письма.

## Что на странице

- Закреплённая навигация и плавная прокрутка к разделам
- Герой с очередью дня
- Сетка возможностей
- Тарифы с переключением месяц / год
- Истории клиентов
- Форма почты (демо: адрес остаётся только в браузере)

Исходник страницы: [src/components/landing/home.tsx](src/components/landing/home.tsx).

## Запуск

```bash
npm install
npm run dev
```

## Сайт

Страница публикуется на GitHub Pages при каждом пуше в `main`:

https://krapivin1986.github.io/klaro/

GitHub Pages отдаёт только статику, поэтому сборка делает снимок лендинга с префиксом `/klaro/`. Серверная версия для Vercel этим не заменяется.
